# 收益率走势图 - 后端联动 + 前后端改造

## 背景
用户反馈 YieldChart 组件两个问题：
1. **坐标轴看不清** — SVG `preserveAspectRatio="none"` 拉伸导致文字模糊
2. **点击效果不对** — 周期切换按钮点击无实际效果，因为仅本地过滤 7 个数据点

## 后端改造

### 新增接口
**`GET /api/portfolios/{portfolio_id}/yield?period=1m|3m|1y|all`**
- 支持按 portfolio_id 查询指定组合的收益率曲线
- 优先从 `portfolio_snapshot` 表查询快照数据
- 无快照时回退到 `portfolio.mini_chart_data`
- 按 period 参数过滤时间范围（1月/3月/1年/全部）

### 新增文件模块
- `app/schemas.py`: 新增 `YieldResponse` schema（data/list + dates/list + total_return/daily_return）
- `app/routers/portfolio.py`: 新增 `get_portfolio_yield()` 路由

## 前端改造

### YieldChart.jsx（重写）
- **可视化修复**：SVG 只画曲线和填充，刻度标签全部用 HTML `<div>` 绝对定位渲染，保证字体清晰
- **后端联动**：接收 `portfolioId` prop，周期切换时调用 `portfolioApi.getYield()` 从后端拉数据
- **响应式宽度**：使用 `ResizeObserver` 获取容器实际宽度，X/Y 坐标全部基于实际像素计算
- **Tooltip**：使用 `getBoundingClientRect()` 实际像素定位，不再用 viewBox 百分比
- **底部概览**：显示数据时间范围和累计收益率

### 其他文件变更
- `api.js`: 新增 `portfolioApi.getYield(id, period)` 方法
- `PortfolioDetailScreen.jsx`: 传入 `portfolioId={portfolio.id}` 给 YieldChart
- `App.jsx`: 用 MainLayout 包裹路由，固定 TabBar 显隐问题
- `PortfolioListScreen.jsx`: 删除内部 BottomNavigationBar（已由 MainLayout 统一管理）

## 验证结果
```
GET /api/portfolios/1/yield?period=all → 80+ 个快照数据点（2023-06 至 2025-08）
GET /api/portfolios/1/yield?period=1m  → 7 个数据点（2026-06-03 至 2026-06-09）
```
